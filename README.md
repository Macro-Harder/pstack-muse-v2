# pstack for Muse, version 2 (in development)

This repo is the new version of the Muse port of pstack. It is under active development and is not yet the version to install. The current version stands untouched at [Macro-Harder/pstack-muse](https://github.com/Macro-Harder/pstack-muse).

pstack is by Lauren Tan ([@poteto](https://github.com/poteto)), developed in [cursor/plugins](https://github.com/cursor/plugins/tree/main/pstack). This port is unofficial and is not affiliated with or endorsed by Lauren Tan or Cursor.
