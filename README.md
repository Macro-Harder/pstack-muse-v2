# pstack for Muse, version 2

Version 2 of the Muse port of pstack, the coding playbook system that routes a task through a matched playbook: state the goal and a checkable done condition, name the data shape before code, and verify against the real artifact before reporting anything. This version reshapes the playbooks and skills for Muse, its tools, and its agent model.

Version 1 stands at [Macro-Harder/pstack-muse](https://github.com/Macro-Harder/pstack-muse).
